## 🧩 About

**The Forest Map** is a comprehensive map overlay tool for The Forest featuring full map overlay, radar, loot tracker, HUD, waypoint system, and item ESP.

Based on popular tools like **The Forest Map Mod**, **The Forest Trainer**, and **The Forest Cheat Menu**.

---

## ✨ Features

### 🗺️ Map & Navigation
- Full Map Overlay — see the entire island with player position
- Waypoint System — set and follow custom waypoints
- Radar — shows nearby enemies, animals, and points of interest
- Minimap — corner overlay with zoom and rotation

### 📦 Loot & Items
- Loot Tracker — highlights all nearby items and resources
- Item ESP — see items through walls with distance
- Resource Markers — track trees, rocks, and caves
- Container Highlighter — highlight lootable containers

### 🎮 HUD & Interface
- Custom HUD — displays health, stamina, hunger, and temperature
- Enemy ESP — shows cannibals and mutants with health bars
- Animal ESP — track animals for hunting
- Building Helper — shows building placement and snapping

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Insert"` | Toggle overlay |
| `process_name` | String | `"TheForest.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Restrict risky features |
| `map_zoom` | Float | `1.0` | Map zoom level |
